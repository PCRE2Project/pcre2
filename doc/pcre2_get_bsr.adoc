== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

int pcre2_get_bsr(pcre2_compile_context *ccontext, uint32_t *value);
----

== Description

This function gets the convention for processing [.regex]`\R` within a compile context.
The result is zero. Both arguments must be non-const:NULL.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

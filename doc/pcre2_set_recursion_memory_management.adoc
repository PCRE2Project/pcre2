== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

int pcre2_set_recursion_memory_management(
      pcre2_match_context *mcontext,
      void *(*mymalloc)(size_t size, void *mydata),
      void (*myfree)(void *ptr, void *mydata),
      void *mydata);
----

== Description

From release 10.30 onwards, this function is obsolete and does nothing. The
result is always zero.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

pcre2_code *pcre2_code_copy_with_tables(const pcre2_code *code);
----

== Description

This function makes a copy of the memory used for a compiled pattern, excluding
any memory used by the JIT compiler. Without a subsequent call to
func:pcre2_jit_compile(), the copy can be used only for non-JIT matching.
Unlike func:pcre2_code_copy(), a separate copy of the character tables is also
made, with the new code pointing to it. This memory will be automatically freed
when func:pcre2_code_free() is called. The yield of the function is const:NULL if
arg:code is const:NULL or if sufficient memory cannot be obtained.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

void pcre2_jit_stack_free(pcre2_jit_stack *jit_stack);
----

== Description

This function is used to free a JIT stack that was created by
func:pcre2_jit_stack_create() when it is no longer needed. If the argument is
[.c]`NULL`, the function returns immediately without doing anything. For more
details, see the
xref:pcre2jit.adoc[`pcre2jit`]
page.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

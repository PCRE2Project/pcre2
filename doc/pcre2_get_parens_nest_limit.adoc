== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

int pcre2_get_parens_nest_limit(pcre2_compile_context *ccontext,
                                uint32_t *limit);
----

== Description

This function gets, from a compile context, the maximum depth of nested
parentheses in a pattern. The result is zero for success or const:PCRE2_ERROR_NULL if
either argument is [.c]`NULL`.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

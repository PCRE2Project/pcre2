== Synopsis

[synopsis]
....
#include <pcre2.h>

int pcre2_set_offset_limit(pcre2_match_context *mcontext,
                           PCRE2_SIZE limit);
....

== Description

This function sets the offset limit field in a match context. The result is
always zero. The largest value a PCRE2_SIZE variable can hold removes the
offset limit.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

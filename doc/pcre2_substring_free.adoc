== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

void pcre2_substring_free(PCRE2_UCHAR *string);
----

== Description

This is a convenience function for freeing the memory obtained by a previous
call to func:pcre2_substring_get_byname() or
func:pcre2_substring_get_bynumber(). Its only argument is a pointer to the
string. If the argument is const:NULL, the function does nothing.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

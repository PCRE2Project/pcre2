== Synopsis

[source,c,role=prototype]
----
#include <pcre2.h>

int pcre2_get_newline(pcre2_compile_context *ccontext,
                      uint32_t *newline);
----

== Description

This function gets the newline convention within a compile context. The result
is zero for success or const:PCRE2_ERROR_NULL if either argument is const:NULL.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.

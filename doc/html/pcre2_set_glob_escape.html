pcre2_set_glob_escape(3)

PCRE2 10.50-DEV manual; updated 12 Jul 2017

Synopsis

#include <pcre2.h>

int pcre2_set_glob_escape(pcre2_convert_context *ccontext,
                          uint32_t escape_char);

Description

This function is part of an experimental set of pattern conversion functions. It sets the escape character that is used when converting globs. The second argument must either be zero (meaning there is no escape character) or a supported punctuation character. These are the ASCII punctuation characters (or their EBCDIC equivalents), except !, *, -, :, ?, [, ], and ^, which are reserved for glob wildcard or character-class syntax. The default is grave accent if running under Windows, otherwise backslash. The result of the function is zero for success or PCRE2_ERROR_BADDATA if the second argument is invalid.

The pattern conversion functions are described in the pcre2convert documentation.

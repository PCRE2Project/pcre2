== Synopsis

[synopsis]
....
#include <pcre2.h>

int pcre2_get_heap_limit(pcre2_match_context *mcontext,
                         uint32_t *limit);
....

== Description

This function gets the backtracking heap limit from a match context. The result
is zero for success or PCRE2_ERROR_NULL if either argument is NULL.

There is a complete description of the PCRE2 native API in the
xref:pcre2api.adoc[`pcre2api`]
page and a description of the POSIX API in the
xref:pcre2posix.adoc[`pcre2posix`]
page.
